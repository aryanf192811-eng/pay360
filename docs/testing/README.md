# Testing Log

Dated entries only — manual QA checklists, regression notes, and adversarial/security-testing
findings, written as testing actually happens (not reconstructed later from memory).

Naming convention: `YYYY-MM-DD-<topic>.md` (e.g. `2026-09-05-auth-rbac-manual-check.md`).

Newman full-flow run logs for each phase also land here as `YYYY-MM-DD-phaseN-newman.md` with the
pass/fail summary pasted in.
