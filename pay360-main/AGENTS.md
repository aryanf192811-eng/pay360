# PeoplePay360 Design Rules

## Stitch MCP Strict Requirement
**RULE:** You MUST use Stitch MCP strictly for EVERY redesign. 
This is a mandatory rule. Before modifying any React code for a UI redesign, you must:
1. Update the Stitch Design System (`DESIGN.md`) if necessary.
2. Generate the prototype screens using `generate_screen_from_text` in Stitch MCP.
3. Only AFTER generating the prototypes via Stitch, implement them in the codebase. Do NOT skip the Stitch prototyping phase for any UI changes.
